CARDVERSE V25 — สรุปสิ่งที่แก้ไข (รอบนี้แก้ลึกกว่าเดิมมาก)

สาเหตุจริงที่ "ทำอะไรไม่ได้เลย":
app.js ขาดฟังก์ชันหลักของเกมไปทั้งก้อน — ปุ่มต่าง ๆ เรียกฟังก์ชันที่ "ไม่เคยถูกเขียนอยู่ในไฟล์เลย"
ทำให้พังทันทีที่กด (เช็กแล้วในไฟล์ต้นฉบับที่ส่งมา ไม่ใช่ผมทำพังเพิ่มนะครับ):

  - รับ Daily +500  -> เรียก daily()        -> ไม่มีฟังก์ชันนี้เลย
  - สุ่มการ์ด (Gacha) -> เรียก openPack()     -> ไม่มีฟังก์ชันนี้เลย
  - หน้าตลาด/คลังการ์ด -> เรียก cardHTML()    -> ไม่มีฟังก์ชันนี้เลย (การ์ดเลยไม่ขึ้นเลย)
  - เปลี่ยนภาษา TH/EN  -> เรียก setLang()/applyI18n() -> ไม่มี
  - อัปเดตข้อความ/เหรียญ/รูปโปรไฟล์ในทุกหน้า -> toast(), t(), initArtImages(),
    applyProfileMini(), updateCoins(), applyProfileStyle() -> ไม่มีสักตัว
  - ซื้อ/ขายการ์ด -> buyCard()/sellCard() -> ไม่มี

พูดง่าย ๆ คือโครงเกม (game loop) ทั้งหมดหายไป เหลือแต่ระบบย่อยเรื่องรูปภาพ/โปรไฟล์เท่านั้น
ผมเขียนฟังก์ชันที่หายไปทั้งหมดนี้กลับเข้าไปใหม่ ให้ตรงกับโครงสร้างข้อมูล (CARDS, I18N, state)
และ CSS class ที่มีอยู่แล้วในโปรเจกต์ ทดสอบเปิดจริงด้วยเบราว์เซอร์ (Playwright) แล้วว่า:
  ✓ รับ Daily ได้ เหรียญเพิ่มจริง กดซ้ำวันเดียวกันจะเตือนว่ารับไปแล้ว
  ✓ สุ่มการ์ด (Gacha) ทำงาน หักเหรียญ แจกการ์ด มีระบบ Pity การันตี Epic+ ทุก 10 pulls
  ✓ หน้าตลาดขึ้นการ์ดครบ กดซื้อได้ หน้าคลังขายได้
  ✓ เปลี่ยนชื่อ/ฉายา/เลือกรูปโปรไฟล์/บันทึกโปรไฟล์ทำงานถูกต้อง

สองบั๊กที่แจ้งไว้รอบก่อน (แก้แล้วเช่นกัน):
  - getMainCard() เรียก getCustomMainCard() ที่ไม่มีอยู่จริง -> พังทุกครั้งที่ตั้งการ์ดอัปโหลดเองเป็น
    Main Card -> เพิ่มฟังก์ชันนี้แล้ว
  - ปุ่มอัปโหลดรูปโปรไฟล์ถูกผูก event ซ้อนกัน 2 ชุด (ทำงานซ้ำ 2 รอบ) -> ตัดตัวซ้ำออกแล้ว

บั๊กเรื่องรูปหาย/ไอคอนรูปแตกในเมนู "เลือกรูปโปรไฟล์":
  รูปในกริดเลือกอวตารใช้ src="" ในไฟล์ HTML ตรง ๆ พอเปิดไฟล์แบบ double-click (file://) โดยไม่มี
  server เบราว์เซอร์จะพยายามโหลด src ว่างและยิง error ทันทีตั้งแต่ตอนอ่าน HTML — ซึ่งเร็วกว่าที่
  app.js (อยู่ท้ายไฟล์) จะโหลดเสร็จ ทำให้ error handler เรียกใช้ฟังก์ชันที่ยังไม่มีตอนนั้น รูปเลยค้าง
  แตกถาวร -> เอา src="" ออกจาก HTML ทุกไฟล์ ให้ JS เป็นคนตั้งค่า src ให้ตอนโหลดเสร็จแทน

เอาไปใช้จริงไม่ได้) — ส่งไฟล์รูปจริงมาในแชทได้เลยถ้าอยากให้ผมช่วยวางแล้วแพ็กให้ใหม่
