CARDVERSE V26 — สิ่งที่แก้ไขรอบนี้

ตรวจสอบไฟล์ทั้งหมดใหม่ (cross-check ทุกปุ่ม/ทุก onclick ในทุกหน้ากับฟังก์ชันใน app.js
รวมถึง inline script ในแต่ละหน้า) — คราวนี้ไม่พบฟังก์ชันที่ขาดหายแบบรอบ V25 แล้ว
ปุ่มหลักทั้งหมด (Daily, Gacha/pull, ซื้อ/ขายการ์ด, บันทึกโปรไฟล์ ฯลฯ) เชื่อมกับฟังก์ชัน
ที่มีอยู่จริงครบทุกตัว

บั๊กที่เจอและแก้ในรอบนี้:
  - เพลงซ้อนกัน 2 เพลงพร้อมกัน: หน้า Gacha (packs.html) มีเพลงของตัวเอง
    (phrolova-inspired.wav) แยกจากเพลงพื้นหลังทั้งเว็บ (cardverse-chill.wav)
    ถ้าเคยกดเปิดเพลงพื้นหลังจากหน้าอื่นไว้ (musicOn=true) แล้วมาที่หน้า Gacha แล้วกด/แตะ
    อะไรก็ตามเป็นครั้งแรก ทั้งสองเพลงจะพยายามเล่นพร้อมกันจากอีเวนต์ pointerdown/keydown/
    touchstart ตัวแรกที่เกิดขึ้น (คนละ listener แต่ฟังอีเวนต์เดียวกัน) เสียงเลยทับกัน
    -> แก้โดยทำให้เพลงทั้งสองระบบ "กันกันเอง": พอฝั่งไหนเริ่มเล่น จะสั่งหยุดอีกฝั่งอัตโนมัติ
    ตอนนี้จะได้ยินทีละเพลงเท่านั้นไม่ว่าจะกดปุ่มไหนก่อน

สิ่งที่ตรวจแล้วว่ายังปกติดี (ไม่ใช่บั๊กใหม่):

    denia, qingxiao, aemeath) ยังใช้ placeholder ตามที่ตั้งใจไว้ — ไม่ใช่บั๊ก รอแค่คุณใส่
    ไฟล์รูปจริงตามที่ README เดิมอธิบายไว้
  - ฟังก์ชันที่เคยขาดหายในรอบ V25 (daily, openPack, cardHTML, setLang/applyI18n,
    buyCard/sellCard, getCustomMainCard ฯลฯ) ยังอยู่ครบ ทำงานปกติ
