1) แยกโปรไฟล์เป็น 2 หน้า
────────────────────────────────────────────
เดิม profile.html ยัดทั้ง "โชว์เคส" กับ "เครื่องมือแก้ไข" ไว้หน้าเดียว ตอนนี้แยกแล้ว:

• profile.html (ใหม่) — หน้าโชว์เคส อ่านอย่างเดียว ดีไซน์อิงจากภาพ Resonator
  Showcase ที่ส่งมา: พื้นหลังใหญ่ (การ์ดหลักของคุณ) พร้อม Ken Burns effect + แสงลอย,
  การ์ด id ซ้ายบน (อวตาร์ + ชื่อ + แรงค์คอลเลกเตอร์ + bio), แถวสถิติ (Coins, การ์ดที่สะสม,
  สถิติดวล, Pity), และการ์ดโชว์เคส 3 ใบด้านล่าง มีปุ่ม "Edit Profile" ลิงก์ไปหน้าแก้ไข
  — ทั้งหมดเป็น CSS animation ล้วน ไม่มีไฟล์วิดีโอ/รูปภายนอกใดๆ

• profile-edit.html (ใหม่) — เอาเครื่องมือเดิมทั้งหมดมาไว้ที่นี่ (เปลี่ยนชื่อ/ฉายา,
  อัปโหลด+จัดตำแหน่งรูป, เลือกสี, เลือกกรอบการ์ด, ตั้งการ์ดหลัก, ปุ่ม Daily) บวกเพิ่ม
  ตัวเลือกใหม่ "การ์ดโชว์เคส" ให้เลือกการ์ดสูงสุด 3 ใบไปโชว์ในหน้าโปรไฟล์

Rank คอลเลกเตอร์คำนวณจากจำนวนการ์ดไม่ซ้ำที่มี (ทุก 4 ใบ = แรงค์ขึ้น 1)

────────────────────────────────────────────
2) ร้านค้ากรอบการ์ดใหม่ (frames.html)
────────────────────────────────────────────
เพิ่มกรอบการ์ดใหม่ 4 แบบที่ต้องซื้อด้วยเหรียญ (นอกเหนือจาก 4 แบบเดิมที่ฟรีอยู่แล้ว):
  Prism 600 / Void 800 / Aurora 900 / Ember 750

กรอบที่ซื้อแล้วใช้ได้ทั้งเว็บทันที (เปลี่ยนขอบการ์ดทุกใบทุกหน้า) หน้าแก้ไขโปรไฟล์จะโชว์
เฉพาะกรอบที่ซื้อ/มีอยู่แล้วเท่านั้น พร้อมปุ่มลิงก์ไปร้านค้าถ้าอยากได้เพิ่ม

กรอบเป็น cosmetic ล้วนๆ ซื้อทางเดียว ไม่มีการขายคืน จึงเป็นตัวดูดเหรียญออกจากระบบ
เพิ่มอีกทาง ไม่กระทบสมดุลเศรษฐกิจที่ปรับไว้ก่อนหน้านี้
